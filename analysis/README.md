# Preserved analysis sources

These are selected original final analysis/plotting scripts. They were copied, statically parsed and never imported/executed. The two joint/regional main scripts have verified execution-provenance hashes. Consult `docs/PAPER_MAP.md` for inputs and existing outputs.

Historical roots, folder-name assertions, manuscript integrity checks and top-level output creation remain unchanged. Their presence is not permission to write to original workspaces. Runnable path adaptations are pending and must be confined to a separate new analysis workspace. Do not use these files as install/import hooks. E0/E1/E2/E3/E4 results can be inspected through the already copied tables without running any script.
